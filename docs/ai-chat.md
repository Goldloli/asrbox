# AI 对话

[English](ai-chat.en.md)

“对话”是“AI”页面的第三个标签页，与“字幕核对”“字幕翻译”并列。它复用“设置 → AI LLM 提供商”中已配置的提供商，支持两种提问方式：不绑定任务时基于内置答疑资料回答软件用法；绑定任务后把该任务当前版本字幕作为上下文，针对字幕内容提问。会话与消息保存在本地数据库中，关闭并重新打开应用后仍可查看和继续。

## 开始提问

1. 打开“AI → 对话”。
2. 点击“新建会话”，或直接输入问题发送（首次发送会自动创建会话）。
3. 左侧列出历史会话，可随时打开继续，或删除整个会话及其消息；删除会话不影响转写任务、字幕版本和提供商配置。会话标题由首条问题自动截断生成。

回答以打字机方式逐步显示；生成过程中可点击“停止”中止，已生成的部分内容会保留并标记为“已中止”。提供商超时、限流、上下文过长、配置无效等错误会按类型分别提示，已有会话和消息不受影响。

## 绑定字幕任务

会话顶部的“绑定字幕任务”选择器可为当前会话绑定一个已完成转写的任务，或选择“不绑定（仅软件答疑）”。绑定后，提问时系统会注入该任务当前版本的字幕全文（与校对、翻译一致的“当前版本”口径），每句字幕带分:秒时间戳，因此可以回答“某句话在字幕什么时间位置”这类定位问题；字幕更新后继续使用最新版本。绑定关系随会话持久化，可随时更换或解除。

如果绑定任务的字幕和会话历史超出模型可用上下文，系统会在发送前明确提示上下文过长，而不会静默截断字幕；此时可解除绑定或换一个上下文更大的模型。

## 软件答疑

ASRbox 内置一份由用户文档整理的答疑知识库，离线可用。提问时会先做本地关键词检索，命中段落作为上下文提供给模型；未命中时模型仍会作答，但会表明该问题超出内置资料范围，而不是编造功能。

## 隐私边界

发送到 LLM 的内容仅限：当前会话的消息、绑定任务的字幕文本、命中的内置答疑段落。不会发送其他任务的数据、音频或文件、提供商凭据、本地文件路径。本地与远程端点的判定、HTTPS 强制和凭据脱敏与字幕核对一致；远程提供商属于第三方处理，使用前请查看其隐私与保留政策。每次回答请求有 120 秒总时限和 1 MiB 响应上限。
