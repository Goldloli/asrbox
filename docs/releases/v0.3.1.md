# ASRbox v0.3.1

ASRbox `v0.3.1` 为任务中心的转写结果新增"一键替换"页签：在与"转写结果""编辑字幕"并列的新页签中以纯文本形式展示字幕全文，输入搜索词即可看到全文高亮、匹配计数与逐个定位；"替换"只改当前定位处，"全部替换"一次改全部。保存复用批量更新并自动创建恰好一个不可变 `edit` 字幕版本，时间与说话人保持不变，可通过版本历史随时恢复。

[中文 README](https://github.com/Goldloli/asrbox/blob/v0.3.1/README.md) · [English README](https://github.com/Goldloli/asrbox/blob/v0.3.1/README.en.md)

产品仍处于公开测试阶段，不代表稳定版。桌面安装包支持 macOS Apple Silicon 与 Windows x64，均未签名、未公证。

## 下载与升级

- [ASRbox_0.3.1_aarch64.dmg](https://github.com/Goldloli/asrbox/releases/download/v0.3.1/ASRbox_0.3.1_aarch64.dmg) — macOS Apple Silicon 安装包
- [ASRbox_0.3.1_x64-setup.exe](https://github.com/Goldloli/asrbox/releases/download/v0.3.1/ASRbox_0.3.1_x64-setup.exe) — Windows x64 安装程序（NSIS，当前用户安装，不需要管理员权限）
- [SHA256SUMS.txt](https://github.com/Goldloli/asrbox/releases/download/v0.3.1/SHA256SUMS.txt) — 安装包与源码包校验值
- [ASRbox-ffmpeg-source-8.1.2.tar.gz](https://github.com/Goldloli/asrbox/releases/download/v0.3.1/ASRbox-ffmpeg-source-8.1.2.tar.gz) — 内置 FFmpeg 对应源码与构建材料

升级前建议备份应用数据，等待当前任务结束并正常退出 ASRbox，再打开安装包手动替换应用。应用内可检查更新和下载经过校验的安装包，安装仍需手动完成；Web 版提供 Releases 链接。

macOS 可能提示未签名应用（按项目安装说明清除隔离属性即可）；Windows SmartScreen 可能提示"Windows 已保护你的电脑"，选择"更多信息 → 仍要运行"即可。

将全部文件下载到同一目录后校验：

```bash
# macOS
shasum -a 256 -c SHA256SUMS.txt
```

```powershell
# Windows（PowerShell）
Get-FileHash -Algorithm SHA256 .\ASRbox_0.3.1_x64-setup.exe
```
