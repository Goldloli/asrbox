## 新增：多语言字幕翻译

- **多种语言互译**：源语言可选自动识别（含混合语言）或指定语言，目标语言支持预设和自定义，不限于英文翻译成中文。
- **原文独立保留**：选择已保存的原字幕版本开始翻译；译文拥有独立历史，人工修订保存为新版本，不覆盖原文。
- **译文与双语导出**：支持 SRT、VTT、ASS、TXT、JSON、Markdown，可导出纯译文或双语，并选择原文／译文的排列顺序。
- **取消与续译**：按批次保存进度，失败或中断后可手动继续；已经完成的批次保留。取消会停止本地进度，正在发送的提供商请求仍可能继续至超时并计费。

入口：**AI → 字幕翻译**，也可从已完成任务进入。字幕校对是可选步骤；需要先校对时，选择校对后的已保存字幕版本作为翻译来源。

## 新增：LLM 平台兼容设置

- 翻译与校对共用协议、思考模式、输出格式和 JSON／SSE 响应方式设置，自定义提供商也可配置。
- 支持 OpenAI 兼容接口及 DeepSeek、Ollama、Qwen、GLM 的相应协议配置，减少不同接入平台参数差异造成的失败。
- 新增 **“测试翻译与校对”**：使用内置示例显式测试服务，在有限请求内检查可用的输出约束；通过后可应用推荐设置。测试不发送用户字幕，旧配置产生的过期建议不能覆盖新配置。
- Ollama 可请求关闭思考并使用 JSON Schema；需要模型默认行为时，也可在兼容设置中调整。

建议先在 **设置 → AI LLM 提供商** 保存服务配置，再执行能力测试。测试只证明样例在当时可用，不保证所有模型、语言或长篇字幕都能正确处理；非 Chat Completions 接口需要对应适配，不能仅更换 URL 使用。

## 修复与改进

- 翻译请求加入总时限，即使提供商持续发送保活内容，也不会无限等待；界面显示批次等待时间。
- 加强字幕 ID、数量和末段完整性校验；被截断、拒绝或结构不完整的输出不会作为完整结果保存。
- 接受完整 JSON 代码围栏；SSE 解析区分正文与思考内容，并限制响应体大小。
- 更新间接依赖 Nano ID 的安全补丁，保持依赖审计检查。

## 验证与已知限制

发布按项目现有门禁执行版本一致性、依赖审计、后端与前端测试、Rust 检查、浏览器回归、Docker 部署、冻结后端及发布资源校验。具体执行结果见本标签对应的 GitHub Actions；真实模型样例通过不构成通用兼容承诺。

- 翻译质量取决于模型。即使结构校验通过，仍可能出现人名误译、术语不一致、重复句子或跨段内容漂移，分享前请人工检查含义和逐段对应。
- 云端 LLM 会收到请求中的字幕文本与有限上下文，可能收费；不会发送媒体文件或文件名。仅使用本机 Ollama 地址时，字幕处理请求发往本机。
- 提供商 API key 以明文保存在本地 SQLite，并可能进入主动创建的备份。请保护数据目录和备份。
- 模型需单独下载，可能占用较多磁盘与内存。安装包不包含模型权重。
- macOS 数据位于 `~/Library/Application Support/com.goldloli.asrbox/`；删除或替换应用不会自动删除这些数据。
- Docker 为 Linux CPU 部署，不包含 MLX，默认仅绑定回环地址；它不是内置公网安全网关。本版不发布容器镜像，也不提供原生 Windows／Linux 或 Intel Mac 桌面包。
