# ASRbox v0.3.0

![ASRbox 任务中心](https://raw.githubusercontent.com/Goldloli/asrbox/v0.3.0/assets/asrbox-task-center.png)

ASRbox `v0.3.0` 是一次整体重构大版本：统一的专业视觉系统（亮暗同构主题、强调色、命令化工作台）、三栏任务中心与全新的"编辑字幕"模式、整合字幕核对/翻译/对话的 AI 工作台、逐句试听与播放条自由接管，以及发布链路校验清单修复（恢复 v0.2.x 客户端的应用内更新）。

[中文 README](https://github.com/Goldloli/asrbox/blob/v0.3.0/README.md) · [English README](https://github.com/Goldloli/asrbox/blob/v0.3.0/README.en.md)

这是不带 prerelease 标记的 `v0.3.0` Release；产品仍处于公开测试阶段，不代表稳定版。桌面安装包支持 macOS Apple Silicon 与 Windows x64，均未签名、未公证。

升级前建议备份应用数据，等待当前任务结束并正常退出 ASRbox，再打开安装包手动替换应用。应用内可检查更新和下载经过校验的安装包，安装仍需手动完成；Web 版提供 Releases 链接。

macOS 可能提示未签名应用（按项目安装说明清除隔离属性即可）；Windows SmartScreen 可能提示"Windows 已保护你的电脑"，选择"更多信息 → 仍要运行"即可。

将全部文件下载到同一目录后校验：

```bash
# macOS
shasum -a 256 -c SHA256SUMS.txt
```

```powershell
# Windows PowerShell
Get-Content SHA256SUMS.txt | ForEach-Object { $h, $f = $_ -split '  '; if ((Get-FileHash $f -Algorithm SHA256).Hash.ToLower() -ne $h) { throw "$f 校验失败" } }
```

**v0.2.x 客户端的应用内更新已恢复**：v0.2.1 的校验清单带 `./` 路径前缀，桌面更新器无法解析导致应用内下载失败。本版起清单由发布流水线统一生成纯文件名格式，v0.2.0 及之后客户端检查更新即可正常下载本版。

## 统一的专业视觉系统

- 全部页面切换为连续表面：亮色为干净的工作台底色，暗色主题与亮色布局同构（不再是半透明面板加全屏渐变）。
- 可配置强调色（默认橙，另有蓝/紫/粉/红/绿/青/灰），作用于主操作、选中态与焦点环；成功/警告/危险语义色保持固定。
- 首页是单一创作工作台：文件拖入、后端/模型/语言/更多设置一行排布，下方为最近任务列表与固定高度的转写结果窗口。
- 侧边栏对新用户默认显示文字；支持图标模式、界面密度、字体大小与动效偏好，全部本地持久化。
- Ollama、Qwen、OpenAI 等提供商与模型显示正确的品牌图标；全局搜索支持 Cmd/Ctrl+K。

## 任务中心与"编辑字幕"

- 桌面端任务中心为常驻三栏：左侧任务列表（最近/进行中/已完成真实切换）、中央波形播放器与转写结果、右侧任务状态与导出，互不裁切。
- 新增"编辑字幕"模式：与只读转写结果完全相同的行布局（播放跳转、时间范围、说话人标识），仅文字可直接修改；右上角"保存更改"一次提交全部分段并创建恰好一个不可变 `edit` 版本，"放弃更改"可还原。
- 旧版分段编辑器（字幕预览切换、逐段时间/说话人表单、查找替换、全文工具）已移除；底层不可变字幕版本能力不变。

## AI 工作台

- 字幕核对、字幕翻译、对话整合进同一个三栏工作台，各列内部滚动，页面不再无限拉长。
- 每条核对建议都可"播放这句话"试听源片段（到句尾自动停止）；修改原因跟随创建运行时的界面语言（中/英）。
- 本地 Ollama 长字幕核对不再卡死在零进度：本地适配的有界批次、紧凑响应与单请求期限，超时/截断/上下文过长/结构错误自动对半拆分重试，排队与推理状态明确区分。
- 长字幕翻译更快：更大的安全首轮批次（64 段/6000 字符）与紧凑有序响应减少请求数，缺段/错位校验失败仍自动拆分，绝不保存不完整译文。

## 播放体验

- 所有"播放这句话"类句段试听默认仍严格按时间轴播放；"设置 → 通用 → 句段播放冗余"可为前后各加 0.5–3 秒冗余，随前端设置导出导入。
- 句段试听自动停止后，点击底部播放条播放键或拖动进度即可接管为连续自由播放，直到手动暂停或媒体结束。

## 界面语言一致性

健康中心、运行时警告、错误、表单校验、空态、加载/排队/处理状态、Toast 与确认框全部按当前界面语言渲染；稳定错误码与警告有维护中的中英映射，未知动态错误显示本地化概括并仅在技术详情保留原文。模型名、路径、环境变量、HTTP 状态、错误码与依赖包名保持原文。

## 验证与已知限制

发布按项目现有门禁执行版本一致性、依赖审计、后端与前端测试、Rust 检查、浏览器回归、Docker 部署、冻结后端及发布资源校验。具体执行结果见本标签对应的 GitHub Actions。本版开发过程中：后端测试 534 项通过，前端单元测试 47 项通过，开源就绪门禁（含受维护浏览器场景）通过；候选 DMG 完成逐控件实机触达验收（含外置卷媒体 Range 播放与大型模型存储下的健康检查并发响应）。

- 两个平台的安装包均未签名：macOS 有 Gatekeeper 提示，Windows 有 SmartScreen/杀毒软件提示的可能。
- Windows 版仅支持 x64；不提供 Windows arm64、MSI、便携版，也不提供原生 Linux 或 Intel Mac 桌面包。
- CUDA 加速套件仅面向 Windows x64 + NVIDIA 显卡；下载约 2.6GB，安装后占用约 4GB 磁盘，与模型一样不计入安装包。套件启用失败（驱动过旧、校验不符等）会保持 CPU 并显示原因。
- 提供商 API key 以明文保存在本地 SQLite，并可能进入主动创建的备份。请保护数据目录和备份。
- 模型需单独下载，可能占用较多磁盘与内存。安装包不包含模型权重。
- 桌面数据位于 `~/Library/Application Support/com.goldloli.asrbox/`（macOS）或 `%APPDATA%\com.goldloli.asrbox\`（Windows）；删除或替换应用不会自动删除这些数据。
- Docker 为 Linux CPU 部署，不包含 MLX，默认仅绑定回环地址；它不是内置公网安全网关。本版不发布容器镜像。
