# ASRbox v0.4.1

ASRbox `v0.4.1` 是一个以维护与模型扩展为主的版本：本地模型目录新增 **Granite Speech 5.0 2B**（IBM 2026-10-20 发布，Apache-2.0；英语、法语、德语、西班牙语、葡萄牙语和日语转写与标点还原；按官方建议把长音频推理块收紧到 120 秒），同时合入 `v0.4.0` 以来的前端、Rust 与构建依赖维护。本版不改变既有 API、事件、用户数据位置和有模型的行为。

[中文 README](https://github.com/Goldloli/asrbox/blob/v0.4.1/README.md) · [English README](https://github.com/Goldloli/asrbox/blob/v0.4.1/README.en.md)

产品仍处于公开测试阶段，不代表稳定版。桌面安装包支持 macOS Apple Silicon 与 Windows x64，均未签名、未公证。两个平台的冻结候选、真实转写与 Windows 就地升级结果见「验证与已知限制」。

## 新增模型

- **Granite Speech 5.0 2B**（`granite-speech-5.0-2b`，Apache-2.0）：IBM 2026-10-20 发布的多语言模型，支持英语、法语、德语、西班牙语、葡萄牙语和日语转写（输出标点与大小写），无中文转写能力；模型另支持英→中文语音翻译，本应用未提供该入口。字幕时间轴为**近似值**（模型不输出原生时间戳）；长音频按官方建议以 **120 秒**为上限分块推理，4.1 普通版（180 秒）与 4.1 Plus（200 秒）的既有行为不变。模型经 ModelScope 主源下载、Hugging Face 备源回退，约 4.8 GB，按需下载。旧模型 `granite-speech-4.1-2b` / `granite-speech-4.1-2b-plus` 的标识、权重、默认选择与行为保持不变。

## 维护与变更

- 合入 `v0.4.0` 以来的 Dependabot 分组依赖升级：前端依赖多轮更新（含 Bun 运行时）、Rust/Tauri 依赖更新（含 tokio），以及构建工具链维护。均为常规维护，无产品行为变化。
- 模型指南、双语 README、路线图与第三方声明同步到 26 个本地模型（另有 2 个仅 server/Docker 的 NeMo 条目）。

## 验证与已知限制

- **Granite Speech 5.0 2B**（2026-11-09，macOS Apple Silicon CPU）：经托管下载与完整后端转写路径，真实权重完成清晰英文、加噪英文、日语与 152 秒长音频转写，六种导出全部通过，长音频末尾句完整保留；macOS 冻结 sidecar 的 `granite_speech_available` 探针为 true 并完成真实转写。证据见仓库 `backend/real_tests/results/asrbox-granite-speech-5.0-verification-20261109.md` 与 `asrbox-granite-speech-5.0-frozen-macos.md`。
- **未复现相对 4.1 的质量优势**：同一合成样本上，5.0 与 4.1 普通版的清晰英文输出逐字一致（脚本 WER 均 3.1%），日语字符错误率 6.2% vs 7.7%（表记差异），因此本版不宣传速度或准确率提升；模型价值以上游新版本与六语种覆盖为准。
- **平台证据范围**：macOS Apple Silicon CPU 与 Windows x64 均已完成冻结候选与真实转写验证（Windows 侧 `granite_speech_available=true`，安装版 CPU 完成 25.3 秒转写与六种导出，耗时 412.2 秒）。Windows 还完成了 `v0.4.0 → v0.4.1` 同目录就地升级：18 个任务、2,358 个字幕段、18 个字幕版本与 10 个已下载模型目录均原样保留，旧 `granite-speech-4.1-2b` 无需重下即可转写，安装目录无旧依赖残留。证据见 `backend/real_tests/results/asrbox-granite-speech-5.0-windows-verification-20261110.md`。
- **CUDA 真机证据**：在 NVIDIA RTX 2060 SUPER（8 GB，驱动 560.94）上，用官方 Release 的 CUDA 套件（torch 2.11.0+cu128）验证了源码与冻结安装版两条路径：`_speech_lm_device_map()` 返回 `auto`，模型加载到 `cuda:0`，25.3 秒转写 40.9 秒完成（同机 CPU 412.2 秒），输出与 CPU 逐字一致；nvidia-smi 峰值显存 5,086–5,612 MiB（随加载路径不同）。8 GB 显存下 150 秒长音频会触发 accelerate 自动部分下沉到 CPU，属明显变慢的混合执行，因此本版不承诺"全 GPU 加速"。证据见 `backend/real_tests/results/granite-speech-5.0-cuda-verification-20261110.md`。
- **仍未覆盖**：安装包签名与 SmartScreen 流程、GUI 自动化交互、Docker/CI 双平台门禁（task 6.2）不在本次证据范围内；这些项未完成前不代表发布就绪。
- 既有 API 路由、响应字段、事件集合、字幕不可变版本与用户数据位置均未改变；无数据库或模型目录迁移。
