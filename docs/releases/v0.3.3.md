# ASRbox v0.3.3

![ASRbox 模型管理](https://raw.githubusercontent.com/Goldloli/asrbox/v0.3.3/assets/asrbox-models.png)

ASRbox `v0.3.3` 为本地模型目录一次性加入**六个 speech-LM 模型**——**Granite Speech 4.1 2B / 2B Plus**、**Cohere Transcribe 2B**、**ARK-ASR 0.6B / 3B** 与 **Voxtral Mini 3B**——并把 Qwen3-ASR 与 MOSS-Transcribe-Diarize 迁移到统一的 `transformers_speech_lm` 引擎（自带 VAD 长音频切分与时间戳偏移），transformers 由 git pin（内容等于 v5.13.0）升级到 PyPI `5.17.0`。同时修复了一个 Windows 升级安装缺陷：从旧版本就地升级会残留上一版本的依赖元数据，导致升级后所有 speech-LM 模型无法加载。

[中文 README](https://github.com/Goldloli/asrbox/blob/v0.3.3/README.md) · [English README](https://github.com/Goldloli/asrbox/blob/v0.3.3/README.en.md)

产品仍处于公开测试阶段，不代表稳定版。桌面安装包支持 macOS Apple Silicon 与 Windows x64，均未签名、未公证。

升级前建议备份应用数据，等待当前任务结束并正常退出 ASRbox，再打开安装包手动替换应用。应用内可检查更新和下载经过校验的安装包，安装仍需手动完成；Web 版提供 Releases 链接。模型存放在应用数据目录之外时可跨版本复用，无需重新下载。

macOS 可能提示未签名应用（按项目安装说明清除隔离属性即可）；Windows SmartScreen 可能提示"Windows 已保护你的电脑"，选择"更多信息 → 仍要运行"即可。

将全部文件下载到同一目录后校验：

```bash
# macOS
shasum -a 256 -c SHA256SUMS.txt
```

```powershell
# Windows PowerShell
Get-Content SHA256SUMS.txt | ForEach-Object { $h, $f = $_ -split '  '; if ((Get-FileHash $f -Algorithm SHA256).Hash.ToLower() -ne $h) { throw "$f 校验失败" } }
```

## 新增本地模型（六个）

- **Granite Speech 4.1 2B**（4.8 GB）：IBM 开源多语言模型，英/法/德/西/葡/日六语转写，输出带标点与大小写；不支持中文，时间轴为近似值。
- **Granite Speech 4.1 2B Plus**（4.1 GB）：在 2B 基础上提供两种按任务选项切换的互斥模式——默认输出带说话人标签（`[Speaker N]:` → S01/S02）的轮次；开启"词级时间戳"后输出词级时间轴（原生厘秒标签自动解回绕并按词聚合句段）。不支持标点与大小写、不支持中文。
- **Cohere Transcribe 2B**（4.0 GB）：2026 年 3 月英语榜第一的模型，14 语言含中文，速度极快、输出带标点；需要手动选择语言（无自动语种检测），时间轴为近似值。
- **ARK-ASR 0.6B / 3B**（2.5 GB / 7.6 GB）：中英 + 17 个欧洲语种，语种跟随音频；3B 在英文短语音基准上处于第一梯队、中文 AISHELL-1 CER 1.8%，0.6B 更轻量；时间轴为近似值。
- **Voxtral Mini 3B**（9.1 GB）：Mistral 开源离线模型，8 语种自动检测，单遍最长 30 分钟长音频；无中文，时间轴为近似值。

六个模型都能在模型页下载并设为默认，转写页可直接选择。有单条输入上限的模型（Cohere ~35 秒、ARK 30 秒、Granite 按模式 3–9 分钟）会自动按 VAD 切分长音频并保持时间轴连续；下载源默认走 ModelScope 镜像（含 Mistral、IBM、Cohere、ARK 均已入驻），Hugging Face 作为备源，受限仓库（Cohere）在镜像不可用时给出明确的授权失败引导。

## 统一引擎与依赖升级

- **`transformers_speech_lm` 统一引擎**：Qwen3-ASR 与 MOSS-Transcribe-Diarize 迁移到共享的"加载 → 生成 → 解析"核心 + 每模型 adapter，行为不变；后续新增 speech-LM 模型只需目录条目 + adapter。
- **transformers 5.17.0**：修复 Qwen3-ASR 的语言解析与多项 Whisper 长音频问题；新增轻量依赖 `mistral-common[audio]`（Voxtral processor 需要）。
- **模型详情新增许可展示**：数据来自模型状态接口，并为需要署名的许可预留署名展示位；六个新模型全部为 Apache 2.0。
- **模型页新增「语音大模型」分类**；不支持自动语种检测的模型不再出现"自动识别 / 中英混合"语言选项，强制语言缺失时任务以明确原因码失败并本地化提示。

## Windows 升级安装修复

- 此前 Windows NSIS 安装包是就地覆盖升级：上一版本遗留、新版本不再包含的文件会留在安装目录。0.3.2 升级 transformers 后，残留的旧 `tokenizers` 依赖元数据会让升级用户的全部 speech-LM 模型无法导入（全新安装不受影响）。现在安装器在复制新文件前清理自管理目录（`$INSTDIR\binaries`），升级结果与全新安装一致；模型、数据库、上传、导出与 CUDA 套件位于应用数据目录，不受影响。

## 验证与已知限制

发布按项目现有门禁执行版本一致性、依赖审计、后端与前端测试、Rust 检查、浏览器回归、Docker 部署、冻结后端及发布资源校验。具体执行结果见本标签对应的 GitHub Actions。本版开发过程中：macOS 后端测试 576 项通过，Windows 后端测试 574 项通过（2 项平台跳过）、前端单元测试 47 项通过、受维护浏览器回归（85 项）通过、冻结二进制 smoke（含新模型探针）通过；六个新模型在 macOS 与 Windows 打包应用中逐一转写验证（含 Cohere 18 分钟长音频与 Granite/MOSS 既有模型对照）。

- 两个平台的安装包均未签名：macOS 有 Gatekeeper 提示，Windows 有 SmartScreen/杀毒软件提示的可能。
- Windows 版仅支持 x64；不提供 Windows arm64、MSI、便携版，也不提供原生 Linux 或 Intel Mac 桌面包。
- CUDA 加速套件仅面向 Windows x64 + NVIDIA 显卡；下载约 2.6GB，安装后占用约 4GB 磁盘，与模型一样不计入安装包。套件启用失败（驱动过旧、校验不符等）会保持 CPU 并显示原因。
- 新模型下载体积较大（Granite 4.1 GB、Cohere 4.0 GB、ARK 7.6 GB、Voxtral 9.1 GB），请预留磁盘；安装包不包含模型权重。
- Granite plus 的说话人模式与词级时间戳模式不可同时开启；长音频按块切分后说话人编号会在每块重新开始。
- 提供商 API key 以明文保存在本地 SQLite，并可能进入主动创建的备份。请保护数据目录和备份。
- 桌面数据位于 `~/Library/Application Support/com.goldloli.asrbox/`（macOS）或 `%APPDATA%\com.goldloli.asrbox\`（Windows）；删除或替换应用不会自动删除这些数据。
- Docker 为 Linux CPU 部署，不包含 MLX，默认仅绑定回环地址；它不是内置公网安全网关。本版不发布容器镜像。
