将三个文件下载到同一目录后校验：


## 新增：AI 对话助手

- “AI”页新增“对话”标签，复用“设置 → AI LLM 提供商”中已配置的提供商（Ollama、MiniMax、Kimi、DeepSeek、Qwen、GLM 或任意 OpenAI 兼容端点），不需要单独配置。
- 软件使用答疑：内置由用户文档整理的离线知识库，关键词检索命中相关段落后作答（不需要向量模型或外部服务）；问题超出资料范围时会明确说明，而不是编造功能。
- 字幕内容问答：为会话绑定一个已完成转写的任务后，可针对其当前版本字幕提问，例如“总结这段字幕”“有没有提到某句话”“在第几分钟提到的”（注入的字幕带分:秒时间戳）。
- 回答打字机式流式呈现，可随时停止并保留已生成部分；会话与消息本地持久化，可回看、继续和删除，删除会话不影响转写任务与字幕版本。
- 防护与边界：系统提示词包含注入防护（拒绝透露系统指令，资料与字幕仅作为数据处理）；发送到 LLM 的内容仅限当前会话消息、绑定任务字幕与命中答疑段落，不发送其他任务数据、凭据或本地路径。

## 验证与已知限制

发布按项目现有门禁执行版本一致性、依赖审计、后端与前端测试、Rust 检查、浏览器回归、Docker 部署、冻结后端及发布资源校验。具体执行结果见本标签对应的 GitHub Actions。对话功能另经本地 Ollama 模型多轮实测：软件答疑、字幕总结/定位、多轮追问、超纲问题与提示词注入攻击场景均按预期工作。

- 单次提问的上下文有保守的字符预算；绑定超长字幕时会在发送前明确提示上下文过长，可解除绑定或换用上下文更大的模型。
- 提示词注入防护为提示词级缓解，系统提示词本身不含任何凭据或机密。
- 提供商 API key 以明文保存在本地 SQLite，并可能进入主动创建的备份。请保护数据目录和备份。
- 模型需单独下载，可能占用较多磁盘与内存。安装包不包含模型权重。
- macOS 数据位于 `~/Library/Application Support/com.goldloli.asrbox/`；删除或替换应用不会自动删除这些数据。
- Docker 为 Linux CPU 部署，不包含 MLX，默认仅绑定回环地址；它不是内置公网安全网关。本版不发布容器镜像，也不提供原生 Windows／Linux 或 Intel Mac 桌面包。
