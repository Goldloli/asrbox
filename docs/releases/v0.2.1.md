# ASRbox v0.2.1

![ASRbox demo](https://raw.githubusercontent.com/Goldloli/asrbox/v0.2.1/assets/asrbox-demo.gif)

ASRbox `v0.2.1` 聚焦本地 Ollama 翻译链路的实测修复：提供商连接成功却翻不了、译文错位、超时显示不符等问题全部定位并修复；新增模型页天梯图，全目录模型的速度/准确率/能力一档看清；同时修复了无时间戳模型（Qwen3-ASR、SenseVoice）长音频丢内容的恶性问题。

[中文 README](https://github.com/Goldloli/asrbox/blob/v0.2.1/README.md) · [English README](https://github.com/Goldloli/asrbox/blob/v0.2.1/README.en.md)

这是不带 prerelease 标记的 `v0.2.1` Release；产品仍处于公开测试阶段，不代表稳定版。桌面安装包支持 macOS Apple Silicon 与 Windows x64，均未签名、未公证。

## 本地 Ollama 翻译：从“连得上但翻不了”到实测通过

本版修复全部来自真实用户环境（Windows + RTX 5080 + 本地 Ollama）的复现数据：

- **默认 4k 上下文不再截断翻译**：Ollama 提供商改用 Ollama 原生对话 API，每个请求显式携带上下文长度（默认 32768，可在提供商兼容设置中调整“上下文长度”）、关闭思考模式、使用原生 JSON Schema 输出约束且不限输出长度。只兼容 OpenAI 接口的网关可在兼容设置中固定回 OpenAI 协议。
- **超时时限按协议区分**：本地 Ollama 单批请求总时限 300 秒（覆盖冷加载与大批生成），其余协议保持 90 秒；等待提示与超时错误文案显示当前运行实际适用的时限，不再一律写 90 秒。
- **偶发失败自动拆批重试**：`LLM_PROVIDER_TIMEOUT` 与响应覆盖不全/重复（`TRANSLATION_INVALID_RESPONSE`）纳入确定性对半拆分重试（递归到单段、按序合并回同一检查点），不再整批直接失败；单段仍失败则明确报错。
- **译文错位防护**：实测发现小参数本地模型在大批次下会输出“滑窗式”译文——结构合法但相邻段落内容互相重叠。本地 Ollama 初始批次收紧到 16 段/1600 字符（落在实测干净区间）；新增内容合理性校验，相邻译文共享超出源文自身重叠的长公共子串、或整批译文异常膨胀时，自动对半拆分重试，错位数据不再持久化（重复台词行的合法相同译文不误判）。

## 模型页：全目录天梯图

- 模型页打开即见全宽天梯表：每个目录模型一行，速度、准确率、语言覆盖 S/A/B/C 四档评级，GPU/CPU/精确时间轴/说话人分离能力勾标，圆点标记已下载，按综合档位排序。
- 速度与准确率评级来自 Windows + RTX 5080 实测（90 秒中文片段、与 large-v3 的字符一致度），表尾注明口径，标“参考值，非性能保证”；未实测模型按引擎/体量估算并标 `*`。
- 移除旧的“估算跑分”面板（按模型体积启发式、只显示前 4 个，无横向对比价值）。

## 无时间戳模型（Qwen3-ASR、SenseVoice）修复与标注

- **长音频丢内容修复**：这两个家族不输出时间戳，分段合并器把它们的单段零时长结果当作重叠丢弃，导致 18 分钟视频只剩首个分块的约 14 行字幕。现在无时间戳分段先铺满各自分块窗口再做重叠过滤，全文不再丢失。
- **如实标注**：模型页与模型状态元数据不再声称它们支持段级/词级时间戳，统一标注为“近似时间轴”（字幕时间按音频窗口铺排）；用这些模型转写的任务，输出面板同样显示近似时间轴提示，避免把导出字幕当成精确打轴。
- **英文断行修复**：字幕超长切行不再把英文单词切成两半（优先在词边界切分，中文等无空格文本保持原逻辑）。

## 其他界面修复

- 侧边栏版本号胶囊不再因文本过长出框。
- 首页转写板块的最近任务区域在宽屏下与转写结果底部对齐。

## 验证与已知限制

发布按项目现有门禁执行版本一致性、依赖审计、后端与前端测试、Rust 检查、浏览器回归、Docker 部署、冻结后端及发布资源校验。具体执行结果见本标签对应的 GitHub Actions。本版开发过程中：后端测试 515 项通过，开源就绪门禁（含 51 项受维护浏览器场景）通过；翻译修复经本机 Ollama（qwen3.5:9b）真实数据对照实验验证，模型天梯数据来自 RTX 5080 + CUDA 套件实测。

- 两个平台的安装包均未签名：macOS 有 Gatekeeper 提示，Windows 有 SmartScreen/杀毒软件提示的可能。
- Windows 版仅支持 x64；不提供 Windows arm64、MSI、便携版，也不提供原生 Linux 或 Intel Mac 桌面包。
- CUDA 加速套件仅面向 Windows x64 + NVIDIA 显卡；下载约 2.6GB，安装后占用约 4GB 磁盘，与模型一样不计入安装包。套件启用失败（驱动过旧、校验不符等）会保持 CPU 并显示原因。
- 提供商 API key 以明文保存在本地 SQLite，并可能进入主动创建的备份。请保护数据目录和备份。
- 模型需单独下载，可能占用较多磁盘与内存。安装包不包含模型权重。
- 桌面数据位于 `~/Library/Application Support/com.goldloli.asrbox/`（macOS）或 `%APPDATA%\com.goldloli.asrbox\`（Windows）；删除或替换应用不会自动删除这些数据。
- Docker 为 Linux CPU 部署，不包含 MLX，默认仅绑定回环地址；它不是内置公网安全网关。本版不发布容器镜像。
