ASRbox `v0.2.0` 聚焦设置体验：显卡加速按平台分面板展示（macOS 显示 Apple GPU，Windows 显示 CUDA），CUDA 检测失败可直接重新检测；LLM 提供商支持一键拉取可用模型列表；模型页默认展示全部模型并补全中文状态描述；移除全局快捷键与命令面板。

这是不带 prerelease 标记的 `v0.2.0` Release；产品仍处于公开测试阶段，不代表稳定版。桌面安装包支持 macOS Apple Silicon 与 Windows x64，均未签名、未公证。

macOS 可能提示未签名应用（按项目安装说明清除隔离属性即可）；Windows SmartScreen 可能提示“Windows 已保护你的电脑”，选择“更多信息 → 仍要运行”即可。

将全部文件下载到同一目录后校验：

```bash
# macOS
shasum -a 256 -c SHA256SUMS.txt
```

```powershell
# Windows PowerShell
Get-Content SHA256SUMS.txt | ForEach-Object { $h, $f = $_ -split '  '; if ((Get-FileHash $f -Algorithm SHA256).Hash.ToLower() -ne $h) { throw "$f 校验失败" } }
```

## 显卡加速：按平台分面板，检测失败可重试

- **macOS**：“设置 → 显卡加速”现在显示 Apple GPU 面板——Metal/MPS 与 MLX 的可用性，以及会自动走 GPU 的模型列表；不再出现仅适用于 Windows 的 CUDA 开关。Web 及其他平台显示桌面端专属说明。
- **Windows CUDA 面板重构**：更紧凑的双卡片布局；检测失败原因以中文说明替换原始英文报错（原文保留为诊断详情）；涉及重启的文案统一为“重启软件”，不再出现“后端”这类内部说法。
- **重新检测**：显卡状态新增机器可读的 `reason_code`，面板提供“重新检测”按钮（`POST /settings/cuda-acceleration/redetect`）重跑硬件探测；加速套件安装、启用等生命周期事件也会自动重置检测缓存。装好驱动或套件后无需重启整机即可刷新状态——例如先启用 CUDA 加速再检测的场景，不会再一直停在“不可用”。

## LLM 提供商：一键拉取模型列表

新增/编辑 LLM 提供商时，填好 API Key 与接口地址后点“获取模型”即可拉取该端点可用的全部模型 ID，从列表中直接选择填入默认模型，不再需要手动查文档抄写模型名；手动输入仍然保留。

- 拉取在保存前即可用（编辑已有提供商时复用已保存的 Key）；Ollama 自动回退到其原生模型列表接口，本地部署同样一键可选。
- 后端新增 `POST /llm-providers/models` 探测接口，遵循与连接测试相同的有界超时与凭据保护规则：不会把 API Key 回显到响应或日志。

## 模型页与界面调整

- 模型页默认展示“全部”分类，“推荐”调整为第二个筛选项，进入页面即可看到完整模型目录。
- 未下载的模型行不再显示后端英文原句，改为本地化状态描述（中英文界面各自对应）；新增 `GET /models/status` 的 `compatibility_error_code` 机器可读字段支撑展示；仅“未下载”的模型不再混入“需要关注”分组。
- 移除全局快捷键（mod+n / mod+f / mod+, / mod+k）、设置中的快捷键卡片与命令面板；全局搜索保留在顶栏按钮。设置导出/导入不再包含快捷键字段。

## 其他新增与修复

- **Windows 安装包图标**：NSIS 安装/卸载程序改用 ASRbox 应用图标，不再是 NSIS 默认图标。
- **版本号统一工具**：维护者命令 `npm run version:bump -- <X.Y.Z>` 一步更新全部受维护版本来源（package.json、tauri.conf.json、Cargo、后端、Docker、README 锚点、CHANGELOG 链接），并重新跑 `check:versions` 证明一致；`check:versions` 现在也强制校验 CHANGELOG 章节与链接。

## 验证与已知限制

发布按项目现有门禁执行版本一致性、依赖审计、后端与前端测试、Rust 检查、浏览器回归、Docker 部署、冻结后端及发布资源校验。具体执行结果见本标签对应的 GitHub Actions。本版开发过程中：后端测试 493 项通过，开源就绪门禁（含 49 项受维护浏览器场景）通过，macOS DMG 经 `hdiutil verify` 校验有效。

- 两个平台的安装包均未签名：macOS 有 Gatekeeper 提示，Windows 有 SmartScreen/杀毒软件提示的可能。
- Windows 版仅支持 x64；不提供 Windows arm64、MSI、便携版，也不提供原生 Linux 或 Intel Mac 桌面包。
- CUDA 加速套件仅面向 Windows x64 + NVIDIA 显卡；下载约 2.6GB，安装后占用约 4GB 磁盘，与模型一样不计入安装包。套件启用失败（驱动过旧、校验不符等）会保持 CPU 并显示原因。
- 提供商 API key 以明文保存在本地 SQLite，并可能进入主动创建的备份。请保护数据目录和备份。
- 模型需单独下载，可能占用较多磁盘与内存。安装包不包含模型权重。
- 桌面数据位于 `~/Library/Application Support/com.goldloli.asrbox/`（macOS）或 `%APPDATA%\com.goldloli.asrbox\`（Windows）；删除或替换应用不会自动删除这些数据。
- Docker 为 Linux CPU 部署，不包含 MLX，默认仅绑定回环地址；它不是内置公网安全网关。本版不发布容器镜像。
