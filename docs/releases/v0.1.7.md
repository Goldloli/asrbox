ASRbox `v0.1.7` 修复两个转写质量问题：Whisper 系模型在静音或音乐段可能幻觉出数百个连续重复词；Qwen3-ASR 长音频输出会在固定 512 token 处静默截断。同时本地模型选择与下载引导现在标注每个模型支持的 CPU/GPU 推理设备。

[中文 README](https://github.com/Goldloli/asrbox/blob/v0.1.7/README.md) · [English README](https://github.com/Goldloli/asrbox/blob/v0.1.7/README.en.md) · [本地模型文档](https://github.com/Goldloli/asrbox/blob/v0.1.7/docs/models.md)

这是不带 prerelease 标记的 `v0.1.7` Release；产品仍处于公开测试阶段，不代表稳定版。桌面安装包仅支持 macOS Apple Silicon，未签名、未公证。

## 修复：转写重复词幻觉

- Whisper 系引擎（Transformers Whisper、Faster Whisper、MLX Whisper）默认启用防幻觉解码：不再把上一解码窗口文本作为后续窗口的 prompt，并启用重复 n-gram 抑制，避免静音、音乐或低质量音频段产生连续数百个重复词并自我强化。
- 后处理增加跨引擎兜底：任意连续重复 6 次以上的词或字折叠为保留 2 次，不改变字幕时间轴。
- 质量报告的重复检测同时覆盖中文字符级与英文词级重复，异常结果会在任务质量标签中暴露 `REPETITIVE_TRANSCRIPT` 警告。

## 修复：Qwen3-ASR 长音频截断

- Qwen3-ASR 的输出 token 预算不再固定为 512（约 470 个英文词），改为按音频时长自适应（每分钟 320 token，下限 1024，上限 8192），长录音或语速快的片段不再被静默截断。

## 新增：模型设备支持标注

- 模型管理与下载引导标注每个受维护模型支持的推理设备（CPU、CUDA、MPS、MLX），实际运行设备仍取决于当前硬件与运行时。

## 验证与已知限制

发布按项目现有门禁执行版本一致性、依赖审计、后端与前端测试、Rust 检查、浏览器回归、Docker 部署、冻结后端及发布资源校验。具体执行结果见本标签对应的 GitHub Actions。修复另经真实媒体回归：六个本地引擎分别在约 5 分钟至 2.2 小时的中英文真实录音上完成转写，未再出现重复循环或截断。

- 重复折叠对模型幻觉与说话人真实口吃一视同仁；字幕惯例上会清理口吃，需要保留口吃细节时注意这一点。
- 提供商 API key 以明文保存在本地 SQLite，并可能进入主动创建的备份。请保护数据目录和备份。
- 模型需单独下载，可能占用较多磁盘与内存。安装包不包含模型权重。
- macOS 数据位于 `~/Library/Application Support/com.goldloli.asrbox/`；删除或替换应用不会自动删除这些数据。
- Docker 为 Linux CPU 部署，不包含 MLX，默认仅绑定回环地址；它不是内置公网安全网关。本版不发布容器镜像，也不提供原生 Windows／Linux 或 Intel Mac 桌面包。
