ASRbox `v0.1.4` 新增完整的“关于与更新中心”：现在可以直接在设置中查看版本、运行平台、作者和项目支持入口，选择稳定版或预发布版，并在桌面端检查和下载新版本。整个更新流程仍保持透明可控——ASRbox 不会静默安装更新，安装包必须通过同一 GitHub Release 的 SHA-256 校验后才允许打开。

> 当前 DMG 未签名、未公证，仅支持 Apple Silicon Mac。应用内下载不等于自动安装；下载完成后请结束当前任务、正常退出 ASRbox，再打开 DMG 手动替换。首次打开如提示“ASRbox.app 已损坏”，请按 README 中的 Gatekeeper 指引处理。

下载后建议校验：

```bash
shasum -a 256 -c SHA256SUMS.txt
```

## 本版本变化

- **新增“设置 → 关于”**：集中展示 ASRbox 说明、当前版本、运行平台、公开测试状态、作者 `Goldloli 小卡塔克`、版权，以及 GitHub、哔哩哔哩、Issues、文档、隐私、许可和 Releases 入口。
- **稳定版 / 预发布版通道**：稳定版只比较正式 SemVer；预发布版通道会比较正式版和预发布版。预发布构建首次启动时默认选择预发布通道，用户选择会持久保存。
- **可控的自动检查**：桌面端默认在启动约 10 秒后检查更新，此后最多每 24 小时自动检查一次；可关闭自动检查或应用内通知，也可以随时手动强制检查。
- **应用内通知**：发现新版本时使用 ASRbox Toast 和设置角标提示，不发送操作系统通知，也不会自动开始下载。
- **应用内下载安装包**：Apple Silicon 桌面端可把 DMG 下载到系统“下载”目录，显示百分比、字节数、速度和预计剩余时间，并支持取消、失败重试和全局任务中心追踪。
- **严格校验与安全边界**：只接受 `Goldloli/asrbox` 官方 HTTPS Release 中与版本和平台完全匹配的 DMG；下载先写入 `.part`，字节数和 SHA-256 均匹配后才生成正式文件。额外拒绝异常跳转、路径穿越资源名和符号链接复用。
- **跨平台措辞与 Web 降级**：完成后提供“打开 DMG”和“打开文件所在位置”；Web 版只显示构建版本和 Releases 链接，不会把桌面安装包下载到服务器。
- **设置迁移**：更新通道、自动检查和通知偏好已纳入现有设置导入导出。
- **文档同步**：README、隐私、发布和故障排查文档已补充更新检查、网络访问、手动替换、校验和未签名限制。
- 全部变化见 [CHANGELOG](https://github.com/Goldloli/asrbox/blob/v0.1.4/CHANGELOG.md)。

## 已知限制

- 仅发布 macOS Apple Silicon DMG；Docker 为 Linux CPU（不含 MLX），默认绑定回环地址。
- 当前安装包未签名、未公证，仍可能触发 macOS Gatekeeper；应用内下载不会绕过系统安全检查。
- 这不是 Tauri Updater 自动安装：ASRbox 不会自动退出、覆盖旧应用或重启，用户需要手动完成替换。
- `SHA256SUMS.txt` 保证下载完整性，但与 DMG 来自同一 GitHub Release；独立更新签名留待未来引入 Apple Developer ID 或专用 updater 签名时实现。
- Provider 密钥仍在本地数据库中明文存储；模型需单独下载，可能占用较多磁盘与内存。
