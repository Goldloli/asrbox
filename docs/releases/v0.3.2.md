# ASRbox v0.3.2

![ASRbox 模型管理](https://raw.githubusercontent.com/Goldloli/asrbox/v0.3.2/assets/asrbox-models.png)

ASRbox `v0.3.2` 为本地模型目录加入三个新模型——**Paraformer Large 中文**、**Fun-ASR-Nano** 与 **Faster Whisper Distil Large V3**，并修掉一批只出现在打包版里的问题：此前安装包无法加载 faster-whisper 模型和带 VAD 的 FunASR 模型，且 CPU 推理被限制为单线程。修好后大型模型转写快约 4 倍：实测 18 分 05 秒英文视频由约 10 分钟降到约 2 分钟，字幕输出逐字一致。

[中文 README](https://github.com/Goldloli/asrbox/blob/v0.3.2/README.md) · [English README](https://github.com/Goldloli/asrbox/blob/v0.3.2/README.en.md)

产品仍处于公开测试阶段，不代表稳定版。桌面安装包支持 macOS Apple Silicon 与 Windows x64，均未签名、未公证。

## 新增本地模型

- **Paraformer Large 中文**（850 MB）：FunASR 生态的中文模型，输出原生字级时间戳并聚合为句段，字幕时间轴精确；默认启用 VAD 切分，长音频友好。
- **Fun-ASR-Nano**（2.0 GB）：通义 2025 新架构，多语种（中、含方言、英、日、韩、粤语），中文准确率与 Paraformer 同级；时间轴为近似值（模型不输出时间戳）。
- **Faster Whisper Distil Large V3**（1.4 GB）：英文专用（不能用于中文等其它语言），速度约为 Large V3 的两倍、精度接近，适合英文批量与长音频转写。

三个模型都能在模型页下载并设为默认，转写页可直接选择；模型页「模型天梯」中它们的等级来自真实音频实测，与目录内既有模型用同一口径比较。

## 打包版修复与性能

- **faster-whisper 模型在安装包里直接失败**：冻结包缺少 Silero VAD 资源（`silero_vad_v6.onnx`），所有 faster-whisper 转写都会以 `MODEL_LOAD_FAILED` 结束。现已随包分发。
- **带 VAD 的 FunASR 模型（Paraformer）加载失败**：funasr 中 `@torch.jit.script` 依赖的源码未打进包，导致模型类未注册。现按已安装版本自动收集，Windows 上的打包目标路径统一为 POSIX 分隔符。
- **打包版 CPU 推理被限制为单线程**：冻结版为加快启动把 `OMP_NUM_THREADS` 固定为 1，转写 worker 继承后 CTranslate2 只用一个核。现在 worker 自行设置线程数（按 CPU 核数与本地并发上限分摊），主进程仍保留启动期的保守设置。实测推理期间 CPU 由约 100%（单核）升到约 400%（多核），18 分 05 秒英文视频 600.9 秒 → 120.5 秒、90 秒片段 57–60 秒 → 15.1 秒，字幕段数与字符数完全一致。
- **重启后端可能起不来**：桌面壳停止路径现在等待 17494 端口释放，健康探测不再把中途失败的请求当作致命错误。
- 顺带修正模型页两处文案：Distil 详情的能力列表不再同时写"多语言识别"与"仅英文"；天梯脚注改为覆盖 Windows 与 macOS 两轮实测。

## 验证与已知限制

发布按项目现有门禁执行版本一致性、依赖审计、后端与前端测试、Rust 检查、浏览器回归、Docker 部署、冻结后端及发布资源校验。具体执行结果见本标签对应的 GitHub Actions。本版开发过程中：后端测试 550 项通过、前端单元测试 47 项通过、受维护浏览器回归（85 项，含新增的下载态布局断言）通过、冻结二进制 smoke（含包内资源断言）通过；打包版与开发环境做过 7 个模型 / 4 个引擎的对照实测，热态下逐模型持平。

- 两个平台的安装包均未签名：macOS 有 Gatekeeper 提示，Windows 有 SmartScreen/杀毒软件提示的可能。
- Windows 版仅支持 x64；不提供 Windows arm64、MSI、便携版，也不提供原生 Linux 或 Intel Mac 桌面包。
- CUDA 加速套件仅面向 Windows x64 + NVIDIA 显卡；下载约 2.6GB，安装后占用约 4GB 磁盘，与模型一样不计入安装包。套件启用失败（驱动过旧、校验不符等）会保持 CPU 并显示原因。
- 提供商 API key 以明文保存在本地 SQLite，并可能进入主动创建的备份。请保护数据目录和备份。
- 模型需单独下载，可能占用较多磁盘与内存。安装包不包含模型权重。安装新构建后的第一个转写任务会略慢（首次加载新二进制），随后恢复正常。
- 桌面数据位于 `~/Library/Application Support/com.goldloli.asrbox/`（macOS）或 `%APPDATA%\com.goldloli.asrbox\`（Windows）；删除或替换应用不会自动删除这些数据。
- Docker 为 Linux CPU 部署，不包含 MLX，默认仅绑定回环地址；它不是内置公网安全网关。本版不发布容器镜像。
