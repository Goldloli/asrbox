ASRbox `v0.1.9` 新增 Windows x64 桌面端：与 macOS 版同一套 Tauri 2 + 内置 FastAPI sidecar 架构，提供 NSIS 安装包；应用内更新检查、校验下载与全部本地转写能力在两个平台一致。

[中文 README](https://github.com/Goldloli/asrbox/blob/v0.1.9/README.md) · [English README](https://github.com/Goldloli/asrbox/blob/v0.1.9/README.en.md)

这是不带 prerelease 标记的 `v0.1.9` Release；产品仍处于公开测试阶段，不代表稳定版。桌面安装包支持 macOS Apple Silicon 与 Windows x64，均未签名、未公证。

macOS 可能提示未签名应用（按项目安装说明清除隔离属性即可）；Windows SmartScreen 可能提示“Windows 已保护你的电脑”，选择“更多信息 → 仍要运行”即可。

将全部文件下载到同一目录后校验：

```bash
# macOS
shasum -a 256 -c SHA256SUMS.txt
```

```powershell
# Windows PowerShell
Get-Content SHA256SUMS.txt | ForEach-Object { $h, $f = $_ -split '  '; if ((Get-FileHash $f -Algorithm SHA256).Hash.ToLower() -ne $h) { throw "$f 校验失败" } }
```

## 新增：Windows x64 桌面端

- NSIS 安装包，当前用户安装；启动后在 `127.0.0.1:17494` 运行内置后端，API token 仅存在于内存，退出应用即停止 sidecar。
- 内置 Windows 版 FFmpeg/ffprobe（gyan.dev GPL 构建，与 macOS 内置版本同为 ffmpeg 8.1.2）；本地转写、模型管理、AI 核对与对话、导出等能力与 macOS 版一致。
- 应用内更新检查在 Windows 上识别并下载 `ASRbox_<版本>_x64-setup.exe`，按同一 Release 的 `SHA256SUMS.txt` 校验后才允许打开。
- 后端测试套件（423 项）在 Windows 全部通过；CI 新增 Windows 后端回归 job，Release 工作流新增 Windows 打包 job，与 macOS 并行产出并发布到同一 Release。

## 新增：NVIDIA CUDA 加速套件（Windows x64）

Windows 桌面端新增可选的 GPU 加速：在“设置 → 显卡加速”页打开开关，应用一次性下载约 2.6GB 的加速套件（torch 2.11.0+cu128 运行时），自动完成 SHA-256 校验、安装与后端重启，之后本地模型转写走 NVIDIA GPU；关闭开关即回退 CPU。安装包本身不变（仍约 430MB），套件按需获取，应用升级不受影响。

- 硬件前提：Windows x64 + NVIDIA 显卡（套件自带 CUDA 12.8 运行时，需支持 CUDA 12.8 的显卡驱动）；不满足时开关不可用并保持 CPU。
- 下载与校验：套件按字节分卷发布，逐卷与解压后逐文件 SHA-256 复核，任一不符即整体作废，可重试；下载支持断点续传与取消。
- 诚实状态：开关状态、`/health` 的 `gpu_available` 与设置页均以实际运行时 probe 为准；套件与本版后端 torch 版本不匹配（如跨版本升级）会标记为"已失效"并提示重新下载。
- macOS 版不受任何影响：加速套件仅面向 Windows，macOS 继续走既有的 Apple Silicon（MLX/Metal）路径。

## 其他新增与修复

- **转写默认值**：设置页“转写默认值”新增默认模型选项，可把常用本地模型（如 qwen3-asr）或某个已启用的线上接口设为默认；配合既有默认转写语言（含自动识别），新建转写页会自动选中这些默认值，默认值失效（模型被删、接口被禁用）时自动回退到第一个可用项。macOS、Windows 与 Web 行为一致。
- **Windows 控制台窗口修复**：Windows 版启动与运行期间不再弹出黑色控制台窗口——应用主程序改为 GUI 子系统构建，后端探测、转写 worker、ffmpeg 等子进程统一以无窗口方式创建。

## 验证与已知限制

发布按项目现有门禁执行版本一致性、依赖审计、后端与前端测试、Rust 检查、浏览器回归、Docker 部署、冻结后端及发布资源校验。具体执行结果见本标签对应的 GitHub Actions。

- 两个平台的安装包均未签名：macOS 有 Gatekeeper 提示，Windows 有 SmartScreen/杀毒软件提示的可能。
- Windows 版仅支持 x64；不提供 Windows arm64、MSI、便携版，也不提供原生 Linux 或 Intel Mac 桌面包。
- CUDA 加速套件仅面向 Windows x64 + NVIDIA 显卡；下载约 2.6GB，安装后占用约 4GB 磁盘，与模型一样不计入安装包。套件启用失败（驱动过旧、校验不符等）会保持 CPU 并显示原因。
- 提供商 API key 以明文保存在本地 SQLite，并可能进入主动创建的备份。请保护数据目录和备份。
- 模型需单独下载，可能占用较多磁盘与内存。安装包不包含模型权重。
- 桌面数据位于 `~/Library/Application Support/com.goldloli.asrbox/`（macOS）或 `%APPDATA%\com.goldloli.asrbox\`（Windows）；删除或替换应用不会自动删除这些数据。
- Docker 为 Linux CPU 部署，不包含 MLX，默认仅绑定回环地址；它不是内置公网安全网关。本版不发布容器镜像。
