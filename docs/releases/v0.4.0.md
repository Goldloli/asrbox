# ASRbox v0.4.0

ASRbox `v0.4.0` 带来中文转写质量上限最高的新模型、服务器部署的新引擎，以及一轮翻译管线的系统性加固：本地模型目录新增 **FireRedASR2 AED 1.1B**（小红书开源，中文公开基准第一，词级时间戳）；Docker/server 部署新增 **NeMo 引擎**（Parakeet TDT 0.6B v3 / Canary 1B Flash，需 NVIDIA GPU）；翻译侧把三类此前会**静默发布**的坏译文——跨段错位、源文回显/元评论/占位符——全部改为自动重译或明确失败；本地转写 worker 增加活跃心跳，慢音频块不再被停滞检测误杀。

[中文 README](https://github.com/Goldloli/asrbox/blob/v0.4.0/README.md) · [English README](https://github.com/Goldloli/asrbox/blob/v0.4.0/README.en.md)

产品仍处于公开测试阶段，不代表稳定版。桌面安装包支持 macOS Apple Silicon 与 Windows x64，均未签名、未公证。

将全部文件下载到同一目录后校验：

```bash

```

```powershell
# Windows PowerShell
Get-Content SHA256SUMS.txt | ForEach-Object { $h, $f = $_ -split '  '; if ((Get-FileHash $f -Algorithm SHA256).Hash.ToLower() -ne $h) { throw "$f 校验失败" } }
```

## 新增内容

- **FireRedASR2 AED 1.1B**（本地模型，路线图阶段 3 引擎部分）：中文公开基准第一（AISHELL-1 CER 0.57%），支持中文、英文与语码切换，输出词级时间戳并聚合为句段时间轴，Apache-2.0。推理代码以最小集内置于应用（特征提取改用 torchaudio 的 Kaldi 兼容 fbank，数值等价已验证），零新增 Python 依赖；单次输入上限 60 秒，长音频自动 VAD 切分。已在 macOS 以真实模型经完整后端路径验证转写与全部六种导出格式。
- **NeMo 引擎**（路线图阶段 4，仅 server/Docker 部署）：新增 `parakeet-tdt-0.6b-v3`（25 个欧洲语言、词级时间戳）与 `canary-1b-flash`（英德法西）两个 CC-BY-4.0 模型，署名在模型详情中展示。CUDA-only，桌面版完全隐藏这些条目；CPU 容器中目录可见但转写会给出需要 CUDA 的明确错误。**该引擎尚未在 CUDA 真机上完成验证**（仓库 CI 无 CUDA runner），待验证清单见仓库内 `backend/real_tests/results/nemo-cuda-verification-pending.md`。

## 修复内容

- **翻译跨段错位不再静默发布**：内容合理性校验改为按译文长度归一化（原阈值按英文长度标定，中文短句重复一律漏判），并在全部批次完成后、写入译文版本之前对完整结果再校验一次；命中的段先自动定点重译一次，仍不通过则运行以 `TRANSLATION_ALIGNMENT_UNVERIFIED` 明确失败并保留已成功批次（界面有中英提示）。可能按次计费的协议不会在首次运行发起额外请求，"不会自动付费重试"的承诺不变。
- **翻译完整性新增三条逐段判据**：整段译文回显源文、模型元评论外泄（如「（注意：根据要求…）」「(Note: …)」）、整段占位符译文（如「（无翻译）」）。这三类污染此前能逃过全部批量判据被直接发布；名称、符号、已是目标语言的合法原样返回不受影响。
- **本地转写 worker 活跃心跳**：心跳证明推理仍在推进（进程 CPU 时间持续前进），慢 chunk 不再被停滞时限误杀，推理期间任务行时间戳周期性刷新；进程存活但心跳冻结、或超过硬性上限仍无产出时才判定停滞并终止，本地队列继续可用。
- **本地 Ollama 初始翻译批次上限恢复为 16 段 / 1600 字符**（此前实现偏离为 64 段 / 6000 字符）：实测固定开销可忽略，而大批次在长字幕上更容易触发拆分重译，反而更慢。
- **安全**：间接依赖 source-map-js 更新到 1.2.2，修复 GHSA-68fv-2mgg-jv7q（高危：索引化 source-map section 偏移可造成事件循环拒绝服务）。

## 验证与已知限制

- **FireRedASR2 端到端验证**（2026-10-10，macOS Apple Silicon）：经托管下载路径（ModelScope 源）与完整后端转写路径，真实中文素材产出 27 段词级时间戳字幕，六种导出格式全部通过。证据：`backend/real_tests/results/asrbox-real-models-firered-final.md`。
- **翻译判据标定**：错位判据在 55 次真实本地运行语料上零误报后才落地，并覆盖重复台词行、合法中文两字词、非语音标签等反例；端到端验收（合成跨词字幕的最坏情况，本地 Ollama）全部完成且零漂移。
- **已知限制**：内容整体前移且无重复、无异常长度变化的纯位移翻译仍不可检出；定点重译有界一次，成片塌陷时直接失败而不是逐段重译。界面既有提示"分享前请检查含义、人名和术语"仍是最后一道人工防线。NeMo 引擎未在 CUDA 真机验证；Docker 镜像因内置 `nemo-toolkit` 体积明显增大。Docker 仅支持 Linux CPU 推理、默认绑定回环地址，不是公网网关。提供商 API key 仍以明文存储在本地，请勿在共享环境使用。
