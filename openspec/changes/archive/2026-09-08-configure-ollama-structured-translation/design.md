## 背景

`backend/services/llm_providers.py:chat_completion` 已有 structured_translation 参数，但仅为 DeepSeek 设置输出格式。Ollama 官方 OpenAI compatibility 文档支持 reasoning_effort=none，且思考模型默认启用思考。当前 27B 模型实际请求超时。

## 目标 / 非目标

对 Ollama 翻译使用 JSON 和非思考模式。非目标：改变校对或连接测试、延长时限、替换模型、添加代理、修改模型模板或持久化结构。

## 决策

为 structured_translation 且 preset=ollama 的请求设置 response_format=json_schema、reasoning_effort=none（连接测试不使用 schema）。复用现有参数隔离测试，增加普通 Ollama 请求和自定义同模型名不受影响的断言。相比增加本地代理或模型别名，直接使用已有兼容 API 参数保持配置可追溯。

## 风险

旧 Ollama 可能拒绝参数，保持明确失败，不自动重试；当前用户 0.33.3 需真实请求验证。提供商仅发字幕文本到本机，历史保留。验证聚焦测试、全门禁、冻结包与原任务续译导出。

## 回滚

保留旧应用副本后替换已验证新应用；如有故障恢复旧应用即可，无数据迁移。

真实验证表明，关闭思考后约 43.5 秒返回且 reasoning_content 为空，但普通 JSON 模式仍会拼错 segment_id 字段并漏掉末段。因此由 translation 调用方提供 JSON Schema，约束必需字段、合法 ID、数组长度和禁止额外字段，Ollama 传入该 schema；本地严格校验仍为发布依据，不修补模型错误结果。其他提供商仍保持现有输出设置。

## 验证结果

2026-09-08：64 项聚焦测试、开源总门禁（后端 352 项、Rust 18 项、维护端到端 32 项）和冻结应用启动测试通过。保留旧应用后安装本地构建，通过 ASRbox 界面续译，25/25 段、1/1 批完成并保存译文版本。通过界面导出仅译文及原文在前双语 SRT；两份均为 25 段，时间戳逐段与不可变原版本一致，双语导出包含对应原文和已保存译文。

结构校验不代表语义校验：本次模型输出存在相邻段内容提前和末段重复，已作为后续质量问题单独跟踪并告知用户，当前导出用于人工测试，不能视为已经校对的发布字幕。用户字幕及导出文件均未进入仓库。
