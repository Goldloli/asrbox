## 为什么

ASRbox 当前缺少集中展示产品说明、版本、作者、支持与许可入口的“关于”页面，用户也无法在应用内确认是否存在新版本。现阶段尚未购买 Apple Developer Program，因此需要在保持“未签名、未公证、无自动安装更新”事实不变的前提下，提供透明、可校验且可控的版本检查与手动更新体验。

## 变更内容

- 在设置页新增“关于”标签，展示应用说明、当前版本、运行平台、公开测试版状态、作者与版权，以及 GitHub、哔哩哔哩、文档、Issues、隐私和开源许可入口。
- 新增稳定版 / 预发布版更新通道、自动检查更新和应用内更新通知设置，并纳入现有前端设置持久化与导入导出。
- 桌面端在启动后按最多每 24 小时一次的频率后台检查 GitHub Release；用户也可随时手动强制检查。自动检查和通知均可关闭。
- 桌面端发现新版本后允许用户主动下载对应平台的 DMG，展示进度、大小、速度和预计剩余时间，支持取消、失败重试、跨页面继续以及全局任务中心状态。
- 下载使用系统下载目录中的 `.part` 临时文件，完成后根据同一 Release 的 `SHA256SUMS.txt` 校验；校验通过才生成正式 DMG，失败时不得打开损坏文件。
- 下载完成后提供“打开 DMG”和跨平台的“打开文件所在位置”，由用户退出 ASRbox 并手动替换应用；不自动安装、不自动替换、不自动退出或重启。
- Web 端展示相同的关于信息和构建版本，但只提供 GitHub Releases 跳转，不把桌面安装包下载到 Web 后端。
- 更新检查或下载失败不得影响转写、模型下载、存储或其他既有功能，并始终提供浏览器访问 Releases 的兜底入口。

## 能力（Capabilities）

### 新增能力

- `about-update-management`：规定关于页内容、更新偏好、版本通道、自动与手动检查、应用内通知、桌面安装包下载与校验、Web 端降级，以及失败隔离行为。

### 修改能力

- 无。

## 影响

- 前端：`app/src/routes/SettingsPage.tsx`、设置组件、`uiStore`、应用启动运行时、导航角标、任务中心、桌面能力封装、国际化和设置导入导出。
- 桌面端：`tauri/src-tauri/src/main.rs` 中的版本/更新查询、下载、取消、打开文件命令与进度事件，以及 Tauri 权限和配置。
- 依赖：为流式下载与 SHA-256 校验调整 Rust 依赖及 lock file，并运行依赖审计。
- 发布：继续使用 GitHub Release 中现有 DMG 和 `SHA256SUMS.txt`，不引入 Tauri Updater 构件、更新私钥、Apple Developer ID 签名或公证。
- 测试与文档：增加前端状态/交互、桌面命令和发布元数据相关验证，并同步 README、发布和故障排查文档。
