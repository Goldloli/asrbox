## 背景

参见 [proposal.md](./proposal.md)。现有页面结构主要位于 `app/src/components/AppShell.tsx`、`app/src/routes/TranscribePage.tsx`、`TasksPage.tsx`、`AIPage.tsx`、`ModelsPage.tsx`、`SettingsPage.tsx` 与 `app/src/components/TranscriptViewer.tsx`。已选产品图位于 `测试音视频/渲染图/`。用户提供的真实 DMG 截图和 2026-09-16 桌面实机操作证明，之前的理想化 fixture 没有覆盖真实长文件名、真实任务量、固定视口和实际点击结果。

## 目标 / 非目标

**目标：**

- 让五个主页面在真实桌面数据下与已选产品图保持同一结构、层级、密度和交互语义，并保持亮暗主题同构。
- 让每个显示出来的按钮、页签、筛选、下拉框、开关和播放器控件都有可验证的行为；没有行为的控件直接移除。
- 保留字幕校对、翻译、对话绑定、下载、默认模型联动和设置能力。
- 以真实 Tauri 桌面应用逐控件走查作为完成门禁，自动化检查只作为补充。

**非目标：**

- 不更改既有路由或字幕版本语义；允许为校对运行增加带默认值的界面语言字段与数据库列，并在原音频 contract 内修复冻结桌面端的媒体流式实现。
- 不重画品牌资产，不引入新的 UI 依赖。
- 不在任务中心保留分段编辑入口；底层字幕版本与其它已有编辑能力不在本 change 中删除。
- 不以逐像素复制产品图中的虚构数据替代真实组件行为。

## 决策

1. **产品图与真实运行态共同构成验收真值。** 产品图约束结构、层级、密度和风格；真实 DMG 约束长内容、固定视口和交互结果。任何一项不通过都不得归档。
2. **所有横向工作区都使用显式的溢出契约。** 首页参数栏和任务三栏的直接子项必须使用 `min-width: 0`；最右侧保留安全内边距；宽度不足时在定义的断点重排，而不是裁切按钮或右栏。首页主卡四角使用与结果卡一致的完整圆角，不在模型字段下暴露无助于选择的运行时实现说明。任务三栏表面、边框和背景由同一工作台容器控制，不能出现三种无意的底色。
3. **首页结果与任务结果都是固定高度阅读窗口。** 长转写文本在自身区域滚动，不能把整页推长。首页只显示正文和 SRT/TXT 下载；任务中心显示播放器联动的只读段落列表。不会在任务中心渲染“分段编辑”页签、字幕预览格式切换或逐段表单。
4. **任务详情头部只保留有效信息与操作。** 当前无行为的检索、重复播放、更多和关闭图标全部移除；播放、seek、音量、段落点击集中在播放器和结果列表。左侧“最近任务 / 进行中 / 已完成”必须改变过滤结果、计数和选中指示，空态仍保持合理宽度。
5. **AI 三模式共享框架但保留完整能力。** 页签选中态使用一致的文字强调色和底部指示，不使用孤立的描边方框。校对必须可选择 LLM、开始/重试并展示结果或可诊断错误；本地 Ollama 校对使用 64 段/6000 字符的首轮批次与 300 秒单请求上限，超时、截断、上下文过长或无效结构按批次二分重试。校对结构化输出采用紧凑三元组并兼容读取旧对象格式，降低重复 key 的生成成本。翻译必须在固定视口内看到语言、字幕版本、提供商和开始操作；本地翻译首轮最多 64 段/6000 字符，并以与目标 ID 顺序对应的紧凑字符串数组减少输出 token，仍对数量、非空文本、错位与膨胀做严格验证，异常时二分回退。对话必须提供“未绑定”和可用字幕任务选择，并在状态区反映当前依据。
6. **模型和设置优先可扫描密度。** 模型采用紧凑行式布局，不让单个模型卡占据大半视口；品牌图标、状态、能力、大小和操作在同一行/受控次行，标题、天梯与模型列表共享一致页面内边距。设置页签使用全局一致的选中样式，页签头卡与当前内容卡以明确间距分离并各自保持四角完整圆角；Switch 自身保持固定宽高，行容器可伸展但控件不得伸展，`checked` 轨道必须取当前 `--app-accent`，`unchecked` 使用中性控件底色，滑块保持高对比。
7. **逐控件桌面触达是硬门禁。** 维护一份页面/控件/前置条件/操作/预期/实测结果矩阵。每个可见非破坏性控件都实际执行；删除/清空类控件只触达到确认层并取消。桌面触达、视觉对照、自动化回归三者全部通过后才允许构建最终 DMG，更不得提前归档。
8. **模型目录扫描不得阻塞桌面后端。** 最终 DMG 暴露出大型模型存储下 `/models/status` 与 `/models/storage` 的同步递归扫描会占住 FastAPI 事件循环，连 `/health` 都无法响应。涉及目录遍历、模型兼容性探测和存储汇总的同步工作必须在线程池执行，并用事件循环响应测试覆盖；候选包必须在扫描仍进行时保持健康检查和其它页面可用。
9. **冻结 macOS 后端对外置卷媒体使用可中止的分段读取。** 真实 DMG 中 Starlette `FileResponse` 在打开外置 APFS 卷媒体时可长时间卡死；仅在 `sys.frozen && darwin` 使用受控的系统分段读取子进程，路径仍由数据库与 `resolve_storage_path` 决定，不接受用户任意路径。实现必须正确处理单 Range、`416`、断开时终止子进程，并继续通过 `process_utils.no_window_kwargs()` 避免 Windows 控制台回归。
10. **工作台滚动由列而不是应用主页面拥有。** `/ai` 与 `/tasks` 的 AppShell 主区域使用 `overflow-hidden`，工作台根节点、三栏直接子项和面板全部显式 `h-full min-h-0`；任务列表、中央结果和右侧状态在各自区域滚动。内容增加时不能扩大 document/main 的滚动高度。
11. **校对原因语言属于一次运行的可审计输入。** 前端按当前 `I18nProvider` 的 `zh`/`en` locale 创建校对运行，后端以默认 `en` 的增量字段持久化，并在每个首轮或拆分批次中明确要求使用简体中文或英文撰写简短原因。旧客户端和旧数据库行继续使用默认值，不改变既有建议文本或字幕版本语义。
12. **校对试听复用全局音频播放器并携带有界区间。** 每条建议用其源字幕段的 `start`/`end` 打开同一任务音频；播放器保存 clip 起止边界，到达结束时间即暂停。再次播放时从片段起点开始，避免继续播放后续句子；无有效时间线或音频不可用时隐藏/禁用试听并给出可理解状态。
13. **优化以实际 Ollama 指标为依据，不盲目并发。** 当前机器实测提示词处理约 200 token/s，而 27B 模型输出约 10–11 token/s；旧长校对 14 批耗时约 21 分钟，短任务又被单 worker 排队约 20 分钟。主要成本是串行生成和排队，而不是输入预填充。实现通过更大安全翻译批次、紧凑校对/翻译响应和自动二分减少请求与输出 token，同时在 UI 明确区分 `queued` 与 `running`。由于本机 Ollama 为 `OLLAMA_NUM_PARALLEL=1`，不增加会争抢同一上游的应用 worker；用户仍可主动选择更小模型获得更高生成速度。
14. **用户可见提示由界面语言和稳定语义决定。** React 层不得直接展示后端 `message`、`error`、`warnings` 等动态英文文本作为主提示；优先根据稳定错误码、状态字段或受控运行时警告标识映射到 `zh`/`en` 文案。对暂时没有稳定码的动态第三方错误，主提示使用本地化的安全概括，原始文本只在明确的技术详情区域展示，避免丢失诊断能力。模型名、文件路径、环境变量、HTTP 状态、错误码和依赖包名属于技术标识，不翻译。切换界面语言后，当前页面已有的健康、错误、空态和状态提示立即按新语言重新渲染，不要求重新请求后端。

## 风险

- [真实任务数据在不同机器上差异较大] → 使用仓库许可安全 fixture 覆盖自动化，同时在当前用户数据上进行只读桌面走查；不把用户数据提交进仓库。
- [移除任务分段 UI 误伤底层字幕编辑 contract] → 只移除任务中心入口和渲染路径，不改后端版本、保存和恢复接口。
- [AI 请求依赖本地或在线 LLM 环境] → 分开验证 UI 可达性、请求参数与错误恢复；环境不可用时保留明确错误，不把超时误报为成功。
- [过大的本地批次可能接近模型上下文或请求期限] → 所有首轮批次继续受字符/段数双重限制，超时、截断、上下文或结构异常递归二分；不得用放宽完整性校验换速度。
- [片段试听与用户手动 seek 冲突] → 有界播放只约束从校对建议启动的会话；关闭播放器或打开普通音频会清除片段边界，手动重播从该片段起点开始。
- [Tauri 与 Web 视口表现不一致] → 同尺寸 Web 几何断言后，必须在最终 Tauri 包内再次完成逐控件触达。
- [后端或第三方错误文本无法穷举] → 对维护中的错误码和运行时警告建立显式映射；未知文本显示本地化概括并在技术详情保留原文，既不泄漏英文到主界面，也不掩盖诊断信息。
- [大型模型目录让候选包看似卡在启动中] → 将同步模型扫描移出事件循环；以真实 36 GB 模型存储启动候选包，确认健康检查不被扫描阻塞。
- [外置卷媒体的 Range 读取在冻结 Python 中卡死] → 对 macOS 冻结态使用系统 `dd` 分段读取，每个请求只读目标区间及最多一个对齐块；客户端断开时终止子进程。

## 回滚

前端结构与性能策略可按文件级差异恢复；新增校对语言列为带默认值的增量迁移，回滚代码后旧版本会忽略该列，无需破坏性降级。若桌面发布验证失败，保留源码与测试证据，不归档、不发布、不替换任何既有 Release 资产。
