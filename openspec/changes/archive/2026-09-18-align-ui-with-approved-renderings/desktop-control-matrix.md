# v0.3.0 桌面逐控件验收矩阵

## 规则

- `源代码运行态` 指 2026-09-16 在 1280×720 与 390×844 视口、真实本地任务数据上的交互走查。
- `候选 DMG` 只允许填写从最终构建的 DMG 挂载卷启动后的结果；构建前保持“待验”。
- 非破坏性操作必须实际执行并观察结果。清空、删除、取消任务等破坏性操作只打开确认层并取消。
- 会向第三方发送字幕或对话内容的操作只验证至明确的发送前状态；没有用户确认不得实际传输。
- 任一项出现裁切、无反馈、错误反馈或不可达时，本 change 不得归档。

## 包内后端门禁

- 最终 DMG 中的 arm64 sidecar 已在现有约 36 GB 模型存储上运行。
- `/models/status` 扫描耗时 3.714 秒期间，`/health` 仍在 0.016 秒返回，`/tasks` 仍在 0.060 秒返回；模型盘扫描不再阻塞事件循环。
- 冻结 binary smoke 首次在早期候选构建后冷启动超时；修复媒体读取问题并重建后，最新候选复跑于 155.43 秒通过。保留首次失败记录，不把失败隐藏为通过。
- 最终候选冻结 sidecar 已对外置卷任务执行真实 Range 请求：返回 `206 Partial Content`、`Accept-Ranges: bytes`、`Content-Range: bytes 0-1023/57706700`、`Content-Type: audio/x-wav`，正文为 1024 字节 RIFF/WAVE 数据。
- DMG CRC 校验通过，应用与 sidecar 均为 arm64，版本为 0.3.0，SHA-256 为 `88e87eca9d468302c62d60d09e06a90e6ceef27f00bec5c3c795e10027fb7784`。
