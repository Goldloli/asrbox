## ADDED Requirements

### Requirement: Windows 安装包升级一致性

Windows x64 NSIS 安装包 SHALL 在复制新版本文件之前清理安装器自行管理的安装目录内容，使升级安装完成后的安装树与全新安装一致——上一版本包含、当前版本已不再包含的文件 SHALL 不再存在。清理 SHALL NOT 触及应用数据目录中的模型、数据库、上传、导出与运行时加速套件。

#### Scenario: 从旧版本升级安装

- **WHEN** 用户在同一安装目录上安装新版本，且该目录存在上一版本遗留、新版本不再包含的文件
- **THEN** 安装完成后这些遗留文件不再存在，安装树与全新安装一致

#### Scenario: 全新安装

- **WHEN** 用户在没有既有安装的机器上安装该版本
- **THEN** 安装成功，且安装结果与升级安装一致

#### Scenario: 升级安装保留用户数据

- **WHEN** 用户升级安装到已有应用数据的机器
- **THEN** 已下载的模型、数据库、上传、导出与已安装的运行时加速套件保持不变

#### Scenario: 升级后的打包应用可用

- **WHEN** 用户从上一版本升级安装并启动打包应用
- **THEN** 打包应用的运行时自检不再报告因上一版本依赖元数据残留导致的模型导入失败
