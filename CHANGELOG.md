# Changelog

All notable changes to ASRbox will be documented in this file.

The format follows Keep a Changelog, and versions use Semantic Versioning while the project is pre-1.0.

## [Unreleased]

### Added

- Open source governance files and contribution workflow.
- Pull request and issue templates.
- Normal CI for push and pull request checks.

## [0.1.0-rc.1] - 2026-07-08

### Added

- macOS Apple Silicon prerelease generated by GitHub Release CI.
- Tauri desktop MVP with bundled backend sidecar.
- Bundled ffmpeg/ffprobe for desktop media inspection.
- Web UI reuse for desktop transcription workflow.

### Known Issues

- macOS package is not signed or notarized.
- Windows and Linux packages are not published yet.
